100% Python Introduction to Computer Networks Disaster Resilience

StormNet

A disaster-resilient neighbourhood mesh network designed to preserve life-critical emergency communications and local services when cellular towers and the internet fail.

1. The Problem Statement

The Crisis: When a cyclone or severe flood strikes, mobile towers lose backhaul power and home Wi-Fi routers go dark. While smartphones still have battery, they are rendered useless because they have no tower to talk to.

Existing offline chat applications attempt to bridge this using Epidemic Flooding (blindly copying every message to every phone encountered). This fails catastrophically in real crises:

  • Severe Battery Drain: Endless broadcast re-transmissions kill phone batteries within hours.
  • Radio Spectrum Congestion: Redundant packet copies choke the narrow wireless channels.
  • Zero Priority Awareness: A critical "trapped and bleeding" medical SOS is treated identically to casual chit-chat.
  • Uncoordinated Storage: Ten neighbours independently cache the same news article, while no one saves the local flood evacuation map.

StormNet's Solution: An intelligent mathematical routing and storage layer that turns ordinary devices into a coordinated, delay-tolerant mesh network.

5. Getting Started

To set up and run StormNet locally:

# 1. Clone the repository
git clone https://github.com/chintapavitra6-a11y/StormNet.git
cd StormNet

# 2. Create and activate a virtual environment (Windows PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. Install required libraries
pip install -r requirements.txt

# 4. Run test suite
pytest tests

6. Shared Contracts

To allow all 4 teammates to develop concurrently without merge conflicts, interfaces are locked in common/:

Contract File Purpose
Message common/message.py Standard packet format containing UUID, priority rank (1–5), GPS coordinates, TTL, sender, payload, and cryptographic signature.
Router API common/router_api.py Abstract class defining select_next_hops() so that baseline and predictive routers are interchangeable with one line.
Connectivity Log data/conn_log.npy 3D array (T, N, N) capturing network topology over time (produced by M1, analyzed by M2).
